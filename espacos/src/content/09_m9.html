Objetivos de aprendizagem

Ao final deste módulo você será capaz de:

  • verificar se uma função entre espaços vetoriais é linear;
  • montar a matriz de uma transformação a partir das imagens da base canônica;
  • calcular núcleo e imagem (com bases e dimensões);
  • usar \(\dim N(T)+\dim\text{Im}(T)=\dim V\) e decidir injetividade e sobrejetividade.

9.1 Definição

Transformação linear

Uma função \(T:V\to W\) entre espaços vetoriais é linear se, para todos \(u,v\in V\) e \(\alpha\in\mathbb R\):

\[T(u+v)=T(u)+T(v)\qquad\text{e}\qquad T(\alpha u)=\alpha\,T(u)\]

Ela “respeita” as duas operações. Consequência imediata: \(T(0)=0\).

Exemplo guiado

\(T(x,y)=(x+2y,\ 3x)\) é linear? E \(S(x,y)=(x+1,\ y)\)?

T

\(T(u+v)=(x_1+x_2+2y_1+2y_2,\ 3x_1+3x_2)=T(u)+T(v)\) e \(T(\alpha u)=(\alpha x+2\alpha y,3\alpha x)=\alpha T(u)\). Linear.

S

\(S(0,0)=(1,0)\ne(0,0)\). Não é linear (é uma translação).

Teste rápido de olho

Em \(\mathbb R^n\), \(T\) é linear quando cada coordenada da imagem é uma combinação \(a_1x_1+\cdots+a_nx_n\), sem constantes soltas, sem produtos \(xy\), sem potências, sem \(|x|\) ou \(\sin x\).

9.2 A matriz de uma transformação

Teorema

Uma transformação linear fica totalmente determinada pelas imagens de uma base. Em \(\mathbb R^n\to\mathbb R^m\):

\[T(x)=A\,x,\qquad A=\Big[\ T(e_1)\ \ T(e_2)\ \cdots\ T(e_n)\ \Big]\]

As colunas de \(A\) são as imagens dos vetores canônicos.

Exemplo

\(T(x,y)=(x+2y,\ 3x)\): \(T(e_1)=(1,3)\), \(T(e_2)=(2,0)\), então \(A=\begin{bmatrix}1&2\\3&0\end{bmatrix}\).

Laboratório: veja uma transformação deformar o plano

Escolha a matriz (ou um dos exemplos). Aperte “Iniciar” para ver a grade se transformar continuamente. O quadrado dourado de área 1 vira um paralelogramo de área \(|\det A|\). Quando \(\det=0\), o plano é esmagado numa reta.

9.3 Núcleo e imagem

Núcleo
\[N(T)=\{v\in V:\ T(v)=0\}\]

É subespaço de \(V\). Cálculo: resolva \(Ax=0\).

Imagem
\[\text{Im}(T)=\{T(v):\ v\in V\}\]

É subespaço de \(W\). Cálculo: é gerada pelas colunas de \(A\) (extraia uma base: Módulo 7).

Teorema do Núcleo e da Imagem
\[\dim N(T)+\dim\text{Im}(T)=\dim V\]

Na matriz: (variáveis livres) + (pivôs) = (número de colunas).

Injetora e sobrejetora

Injetora \(\iff N(T)=\{0\}\). Sobrejetora \(\iff\text{Im}(T)=W\). Se \(\dim V=\dim W\), uma implica a outra; com as duas, \(T\) é um isomorfismo (inversível).

Exemplo guiado

\(T:\mathbb R^3\to\mathbb R^2\), \(T(x,y,z)=(x+y,\ y-z)\). Ache núcleo e imagem.

Núcleo

\(x+y=0\) e \(y-z=0\): \(y=t\), \(z=t\), \(x=-t\). \(N(T)=[(-1,1,1)]\), dimensão 1.

Imagem

Pelo teorema, \(\dim\text{Im}=3-1=2=\dim\mathbb R^2\): \(\text{Im}(T)=\mathbb R^2\).

Conclusão

Sobrejetora, não injetora.

Exemplo prático · estudo de caso

A sombra de um objeto (projeção)

Com o sol a pino, a sombra de um ponto \((x,y,z)\) no chão é \(P(x,y,z)=(x,y,0)\). Essa “máquina de sombras” é linear? O que é o núcleo? Dá para reconstruir o objeto a partir da sombra?

Passo 1 · linear

Cada coordenada é combinação de \(x,y,z\) sem constantes: linear, com matriz \(\begin{bmatrix}1&0&0\\0&1&0\\0&0&0\end{bmatrix}\).

Passo 2 · núcleo

\(P(v)=0\iff x=y=0\): o eixo \(z\). Tudo o que está na vertical sobre um ponto da sombra “some”. \(\dim N=1\).

Passo 3 · imagem e teorema

Imagem: o plano do chão, dimensão 2. \(1+2=3\) ✓. Como o núcleo não é \(\{0\}\), \(P\) não é injetora: objetos diferentes podem ter a mesma sombra, e não dá para reconstruir a altura.

Lição: o núcleo mede a informação que a transformação perde. Fotos (3D → 2D) e compressão de dados funcionam assim.

Exemplos resolvidos

Exemplo 1

\(T(x,y)=(xy,\ x)\) é linear?

Contraexemplo

\(T(2(1,1))=T(2,2)=(4,2)\), mas \(2T(1,1)=(2,2)\). Não é.

Exemplo 2

Ache a transformação linear com \(T(1,0)=(2,1)\) e \(T(0,1)=(-1,3)\).

Passo 1

\(T(x,y)=xT(e_1)+yT(e_2)=(2x-y,\ x+3y)\).

Exemplo 3

A derivada \(D:P_3\to P_2\), \(D(p)=p'\), é linear. Ache \(N(D)\) e \(\dim\text{Im}(D)\).

Passo 1

\(p'=0\iff p\) constante: \(N(D)=P_0\), dimensão 1.

Passo 2

\(\dim\text{Im}=4-1=3=\dim P_2\): \(D\) é sobrejetora.

Questões de verificação

De primeira vale 10 XP; na segunda tentativa, 5 XP. Abrir a resolução antes de acertar vale 2 XP.

Verificação 1fácil

Qual é linear?

  1. \(T(x,y)=(x+3,\ y)\)
  2. \(T(x,y)=(x^2,\ y)\)
  3. \(T(x,y)=(2x-y,\ 5y)\)
  4. \(T(x,y)=(|x|,\ y)\)
Passo 1

Só combinações lineares de \(x\) e \(y\), sem constantes nem potências.

Revise: 9.1

Verificação 2fácil

Toda transformação linear leva o vetor nulo em:

  1. vetor nulo
  2. \(e_1\)
  3. qualquer vetor
  4. depende da matriz
Passo 1

\(T(0)=T(0\cdot v)=0\cdot T(v)=0\).

Revise: 9.1

Verificação 3médio

A matriz de \(T(x,y,z)=(x-z,\ 2y)\) é:

  1. \(\begin{bmatrix}1&0\\0&2\\-1&0\end{bmatrix}\)
  2. \(\begin{bmatrix}1&-1\\2&0\end{bmatrix}\)
  3. \(\begin{bmatrix}1&2&-1\end{bmatrix}\)
  4. \(\begin{bmatrix}1&0&-1\\0&2&0\end{bmatrix}\)
Passo 1

\(T(e_1)=(1,0)\), \(T(e_2)=(0,2)\), \(T(e_3)=(-1,0)\) como colunas.

Revise: 9.2

Verificação 4médio

\(T:\mathbb R^4\to\mathbb R^3\) linear com \(\dim N(T)=2\). Então \(\dim\text{Im}(T)\) é:

  1. 1
  2. 2
  3. 3
  4. 4
Passo 1

\(2+\dim\text{Im}=4\Rightarrow\dim\text{Im}=2\).

Revise: 9.3 Teorema

Verificação 5médio

Uma transformação linear \(T:\mathbb R^3\to\mathbb R^2\) pode ser injetora?

  1. sim, sempre
  2. sim, se for sobrejetora
  3. não, nunca
  4. só se \(\det\ne0\)
Passo 1

\(\dim\text{Im}\le2\Rightarrow\dim N\ge3-2=1\): o núcleo nunca é só \(\{0\}\).

Revise: 9.3

Verificação 6difícil

O núcleo de \(T(x,y,z)=(x+y+z,\ x-y)\) é gerado por:

  1. \((1,1,-2)\)
  2. \((1,-1,0)\)
  3. \((1,1,1)\)
  4. \((0,0,1)\)
Passo 1

\(x=y=t\), \(z=-2t\): \(t(1,1,-2)\).

Revise: 9.3

Hora do desafio

Verificação rápida de tudo o que foi visto no módulo

As colunas da matriz de T são:

  1. as linhas de T
  2. os vetores do núcleo
  3. os autovetores
  4. as imagens dos vetores canônicos
\(A=[T(e_1)\ \cdots\ T(e_n)]\).

Se det A = 0 (A quadrada), a transformação:

  1. é inversível
  2. tem núcleo não trivial
  3. é a identidade
  4. dobra áreas
Colunas LD: existe \(x\ne0\) com \(Ax=0\).

O núcleo mede:

  1. o que a transformação “apaga” (leva em 0)
  2. o que ela alcança
  3. a área
  4. o número de linhas
Vetores do núcleo viram zero: informação perdida.

\(\dim N(T)+\dim\text{Im}(T)\) é igual a:

  1. dim do contradomínio
  2. posto
  3. dim do domínio
  4. sempre 3
