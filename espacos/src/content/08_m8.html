Objetivos de aprendizagem

Ao final deste módulo você será capaz de:

  • explicar por que as coordenadas numa base são únicas;
  • calcular \([v]_B\) resolvendo um sistema;
  • montar a matriz de mudança de base \(M_{B\to C}\) (ou \([I]^B_C\));
  • converter coordenadas entre duas bases.

8.1 Coordenadas numa base

Teorema e definição

Se \(B=\{v_1,\dots,v_n\}\) é base de \(V\), todo \(v\in V\) se escreve de um único jeito como \(v=a_1v_1+\cdots+a_nv_n\). Os números \(a_1,\dots,a_n\) são as coordenadas de \(v\) na base \(B\):

\[[v]_B=\begin{bmatrix}a_1\\\vdots\\a_n\end{bmatrix}\]
Por que é único (é aqui que o LI aparece)
Passo 1

Se \(v=\sum a_iv_i=\sum b_iv_i\), subtraia: \(\sum(a_i-b_i)v_i=0\).

Passo 2

Como \(B\) é LI, todos os \(a_i-b_i=0\), ou seja, \(a_i=b_i\).

A base é um “sistema de medidas”

Na base canônica, \((3,5)\) tem coordenadas 3 e 5. Em outra base, o mesmo vetor (a mesma seta) ganha outros números. A ordem dos vetores da base importa: \(B\) é uma base ordenada.

Exemplo guiado

Ache as coordenadas de \(v=(1,4)\) na base \(B=\{(2,1),(-1,1)\}\).

Passo 1
\[a(2,1)+b(-1,1)=(1,4)\iff\begin{cases}2a-b=1\\a+b=4\end{cases}\]
Passo 2

Somando: \(3a=5\Rightarrow a=\frac53\); \(b=4-\frac53=\frac73\).

\([v]_B=\left(\tfrac53,\ \tfrac73\right)\). Confira: \(\frac53(2,1)+\frac73(-1,1)=(\frac{10-7}{3},\frac{5+7}{3})=(1,4)\) ✓.
Laboratório: a grade de uma base

Escolha \(b_1\), \(b_2\) e o vetor \(v\). A grade verde é a “régua” da base \(B\). As coordenadas \([v]_B\) dizem quantos passos de \(b_1\) e de \(b_2\) levam até \(v\).

8.2 Coordenadas em outros espaços

Exemplo guiado · em P₂

Coordenadas de \(p=3+2t-t^2\) na base \(B=\{1,\ 1+t,\ 1+t+t^2\}\).

Passo 1

\(a\cdot1+b(1+t)+c(1+t+t^2)=(a+b+c)+(b+c)t+ct^2\).

Passo 2 · iguale coeficientes

\(c=-1\); \(b+c=2\Rightarrow b=3\); \(a+b+c=3\Rightarrow a=1\).

\([p]_B=(1,3,-1)\). Na base canônica \(\{1,t,t^2\}\), seria \((3,2,-1)\).

8.3 Matriz de mudança de base

Definição

Sejam \(B\) e \(C\) bases de \(V\). A matriz de mudança da base \(B\) para a base \(C\) é a matriz cujas colunas são as coordenadas, na base \(C\), dos vetores de \(B\):

\[M_{B\to C}=\Big[\ [b_1]_C\ \ [b_2]_C\ \cdots\ [b_n]_C\ \Big]\qquad\text{e}\qquad[v]_C=M_{B\to C}\,[v]_B\]

Na notação de muitos livros brasileiros, \(M_{B\to C}=[I]^B_C\). Além disso, \(M_{C\to B}=(M_{B\to C})^{-1}\).

Caso mais comum: C é a canônica

Se \(C\) é a base canônica de \(\mathbb R^n\), as colunas de \(M_{B\to C}\) são os próprios vetores de \(B\). Então \([v]_{can}=M\,[v]_B\) e, para ir da canônica para \(B\), use a inversa: \([v]_B=M^{-1}v\).

Exemplo guiado

Com \(B=\{(2,1),(-1,1)\}\), ache \([v]_B\) para \(v=(1,4)\) usando matriz.

Passo 1 · B → canônica
\[M=\begin{bmatrix}2&-1\\1&1\end{bmatrix},\quad\det M=3\]
Passo 2 · inversa de 2×2
\[M^{-1}=\frac13\begin{bmatrix}1&1\\-1&2\end{bmatrix}\]
Passo 3
\[[v]_B=\frac13\begin{bmatrix}1&1\\-1&2\end{bmatrix}\begin{bmatrix}1\\4\end{bmatrix}=\frac13\begin{bmatrix}5\\7\end{bmatrix}\]

O mesmo resultado da seção 8.1, agora com uma matriz que serve para qualquer \(v\).

Exemplo prático · estudo de caso

Coordenadas de um robô numa esteira inclinada

Um braço robótico trabalha sobre uma esteira inclinada. É mais fácil programá-lo em coordenadas da esteira: \(b_1=(2,1)\) (ao longo da esteira) e \(b_2=(-1,1)\) (atravessando). A câmera da fábrica, porém, mede posições na base canônica. A câmera viu uma peça em \((1,4)\). Que comando o robô deve receber?

Passo 1

O robô precisa de \([v]_B\); a câmera dá \(v\) na canônica. Use \(M^{-1}\) da seção 8.3.

Passo 2

\([v]_B=(\tfrac53,\tfrac73)\): ande \(\frac53\) de \(b_1\) e \(\frac73\) de \(b_2\).

Passo 3 · automatizando

O software calcula \(M^{-1}\) uma vez e, a cada nova peça, faz uma multiplicação matriz × vetor. É assim que robótica, computação gráfica e GPS convertem entre referenciais.

Resposta: comando \((\tfrac53,\tfrac73)\) nas coordenadas da esteira.

Exemplos resolvidos

Exemplo 1

Se \([v]_B=(2,-1)\) com \(B=\{(1,1),(0,3)\}\), quem é \(v\)?

Passo 1

\(v=2(1,1)-1(0,3)=(2,-1)\). (Coincidência: aqui o vetor ficou igual às suas coordenadas.)

Exemplo 2

Coordenadas de \((3,2,1)\) na base \(\{(1,0,0),(1,1,0),(1,1,1)\}\).

De baixo para cima

\(a(1,0,0)+b(1,1,0)+c(1,1,1)=(a+b+c,\ b+c,\ c)\): \(c=1\), \(b=1\), \(a=1\). Resposta \((1,1,1)\).

Questões de verificação

De primeira vale 10 XP; na segunda tentativa, 5 XP. Abrir a resolução antes de acertar vale 2 XP.

Verificação 1fácil

As coordenadas de \((7,-2)\) na base canônica de \(\mathbb R^2\) são:

  1. \((7,-2)\)
  2. \((-2,7)\)
  3. \((1,1)\)
  4. \((7,2)\)
Passo 1

\((7,-2)=7e_1-2e_2\).

Revise: 8.1

Verificação 2fácil

As coordenadas numa base são únicas porque a base é:

  1. ortogonal
  2. canônica
  3. LI
  4. finita
Passo 1

Duas escritas diferentes dariam uma combinação nula não trivial.

Revise: 8.1

Verificação 3médio

As coordenadas de \((5,3)\) na base \(\{(1,1),(1,-1)\}\) são:

  1. \((3,2)\)
  2. \((4,1)\)
  3. \((5,3)\)
  4. \((1,4)\)
Passo 1

\(a+b=5\), \(a-b=3\Rightarrow a=4,\ b=1\).

Revise: 8.1

Verificação 4médio

As coordenadas de \(p=2+3t\) na base \(\{1+t,\ 1-t\}\) de \(P_1\) são:

  1. \((2,3)\)
  2. \((3,2)\)
  3. \((\tfrac12,\tfrac52)\)
  4. \((\tfrac52,-\tfrac12)\)
Passo 1

\(a(1+t)+b(1-t)=(a+b)+(a-b)t\): \(a+b=2\), \(a-b=3\Rightarrow a=\frac52,\ b=-\frac12\).

Revise: 8.2

Verificação 5difícil

Se \(B=\{(1,2),(3,5)\}\), a matriz que leva coordenadas canônicas em coordenadas na base \(B\) é:

  1. \(\begin{bmatrix}-5&3\\2&-1\end{bmatrix}\)
  2. \(\begin{bmatrix}1&3\\2&5\end{bmatrix}\)
  3. \(\begin{bmatrix}5&-3\\-2&1\end{bmatrix}\)
  4. \(\begin{bmatrix}1&2\\3&5\end{bmatrix}\)
Passo 1

\(M=\begin{bmatrix}1&3\\2&5\end{bmatrix}\), \(\det=-1\). \(M^{-1}=\frac{1}{-1}\begin{bmatrix}5&-3\\-2&1\end{bmatrix}=\begin{bmatrix}-5&3\\2&-1\end{bmatrix}\).

Revise: 8.3

Verificação rápida de tudo o que foi visto no módulo

Trocar a ordem dos vetores da base:

  1. não muda as coordenadas
  2. troca a ordem das coordenadas
  3. deixa de ser base
  4. zera as coordenadas
A base é ordenada; as coordenadas acompanham a ordem.

As colunas da matriz de mudança de B para a canônica de ℝⁿ são:

  1. os canônicos
  2. as linhas de B
  3. a inversa de B
  4. os vetores de B
\([b_i]_{can}=b_i\).

Para ir de coordenadas canônicas para coordenadas em B, usamos:

  1. a inversa da matriz de B
  2. a própria matriz de B
  3. a transposta, sempre
  4. o determinante
\([v]_B=M^{-1}v\).

  1. \((c,b,a)\)
  2. \((1,1,1)\)
  3. \((a,b,c)\)
  4. \((a+b+c)\)
