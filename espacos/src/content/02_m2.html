Objetivos de aprendizagem

Ao final deste módulo você será capaz de:

  • escrever um sistema linear como matriz aumentada;
  • escalonar uma matriz com as três operações elementares;
  • calcular o posto e classificar o sistema (SPD, SPI, SI);
  • escrever a solução geral de um sistema indeterminado com parâmetros;
  • entender por que um sistema homogêneo sempre tem solução.
Por que escalonamento numa apostila de espaços vetoriais?

Quase toda pergunta de espaço vetorial (“\(w\) é combinação de \(u\) e \(v\)?”, “esses vetores são LI?”, “qual a dimensão?”) vira um sistema linear. Quem escalona bem resolve o curso inteiro. Por isso este módulo vem antes de tudo.

2.1 Sistema linear e matriz aumentada

Definição

Uma equação linear tem as incógnitas só no 1º grau, sem produtos entre elas: \(2x-y+3z=5\). Um sistema linear é um conjunto delas. Guardamos só os números numa matriz aumentada:

\[\begin{cases}x+2y+z=4\\2x+5y+3z=11\\x+3y+4z=11\end{cases}\quad\longrightarrow\quad\left[\begin{array}{rrr|r}1&2&1&4\\2&5&3&11\\1&3&4&11\end{array}\right]\]

Cada linha é uma equação; cada coluna (antes da barra) é uma incógnita; a última coluna são os termos independentes.

2.2 Operações elementares e escalonamento

As três operações que não mudam as soluções

1. Trocar duas linhas: \(L_i\leftrightarrow L_j\).
2. Multiplicar uma linha por um número \(k\ne0\): \(L_i\leftarrow kL_i\).
3. Somar a uma linha um múltiplo de outra: \(L_i\leftarrow L_i+kL_j\).

Forma escalonada

Uma matriz está escalonada quando: as linhas nulas ficam no fim; o primeiro número não nulo de cada linha (o pivô) fica à direita do pivô da linha de cima. Fica um formato de “escada”. Na forma escalonada reduzida, além disso, cada pivô vale 1 e é o único número não nulo da sua coluna.

Exemplo guiado (método de Gauss)

Resolva o sistema da seção 2.1.

Passo 1 · zere abaixo do 1º pivô (o 1 da linha 1)
\[L_2\leftarrow L_2-2L_1,\ \ L_3\leftarrow L_3-L_1:\quad\left[\begin{array}{rrr|r}1&2&1&4\\0&1&1&3\\0&1&3&7\end{array}\right]\]
Passo 2 · zere abaixo do 2º pivô
\[L_3\leftarrow L_3-L_2:\quad\left[\begin{array}{rrr|r}1&2&1&4\\0&1&1&3\\0&0&2&4\end{array}\right]\]

Escalonada!

Passo 3 · substitua de baixo para cima

\(2z=4\Rightarrow z=2\). \(y+z=3\Rightarrow y=1\). \(x+2y+z=4\Rightarrow x=0\).

Solução: \((x,y,z)=(0,1,2)\).
Laboratório: escalonador passo a passo (com frações exatas)

Digite qualquer matriz. O laboratório mostra cada operação elementar, o posto e, se for sistema, a classificação e a solução geral. Use os botões SPD, SPI, SI e Homogêneo para ver os três casos.

2.3 Posto e classificação

Posto

O posto de uma matriz é o número de pivôs (linhas não nulas) depois de escalonar.

Situação na forma escalonadaClassificaçãoSoluções
Aparece uma linha \([0\ 0\ \cdots\ 0\,|\,c]\) com \(c\ne0\)SI (impossível)nenhuma
Não há essa linha e posto = nº de incógnitasSPD (possível e determinado)uma só
Não há essa linha e posto < nº de incógnitasSPI (possível e indeterminado)infinitas
Variáveis livres

No SPI, as incógnitas cujas colunas não têm pivô são livres: viram parâmetros (\(t, s, \dots\)). O número de variáveis livres é \(\text{incógnitas}-\text{posto}\).

Exemplo guiado · SPI

Resolva \(\begin{cases}x+y+2z=3\\2x+2y+4z=6\\x-y=1\end{cases}\).

Passo 1 · escalone
\[\left[\begin{array}{rrr|r}1&1&2&3\\2&2&4&6\\1&-1&0&1\end{array}\right]\to\left[\begin{array}{rrr|r}1&1&2&3\\0&-2&-2&-2\\0&0&0&0\end{array}\right]\]

(\(L_2\leftarrow L_2-2L_1\) zera a linha 2; \(L_3\leftarrow L_3-L_1\) dá \((0,-2,-2\,|\,-2)\); por fim troque \(L_2\) e \(L_3\).)

Passo 2 · posto 2 < 3 incógnitas: SPI com 1 livre

\(z\) não tem pivô: \(z=t\). Da linha 2: \(-2y-2t=-2\Rightarrow y=1-t\). Da linha 1: \(x=3-y-2t=2-t\).

Solução geral: \((x,y,z)=(2-t,\ 1-t,\ t)=(2,1,0)+t(-1,-1,1)\), \(t\in\mathbb R\). Geometricamente, uma reta no espaço.

2.4 Sistemas homogêneos

Definição

Um sistema é homogêneo quando todos os termos independentes são zero: \(AX=0\). Ele sempre tem a solução trivial \(X=0\). Então só há dois casos: SPD (só a trivial) ou SPI (infinitas).

Regra de bolso

Homogêneo com mais incógnitas que equações é sempre SPI (o posto não pode passar do número de equações). Essa regra vai explicar por que “3 vetores em \(\mathbb R^2\) são sempre LD” no Módulo 6.

Prévia do que vem

As soluções de um sistema homogêneo formam um subespaço (Módulo 4): somando duas soluções ou multiplicando uma solução por um número, continua sendo solução. Já um sistema com termos independentes não nulos não tem essa propriedade.

Exemplo prático · estudo de caso

Balanceando uma reação química

Para balancear \(x\,\text{C}_3\text{H}_8+y\,\text{O}_2\to z\,\text{CO}_2+w\,\text{H}_2\text{O}\) (queima do propano), o número de átomos de cada elemento tem que ser igual dos dois lados.

Passo 1 · uma equação por elemento

C: \(3x=z\). H: \(8x=2w\). O: \(2y=2z+w\). Passando tudo para a esquerda, é um sistema homogêneo com 4 incógnitas e 3 equações.

\[\left[\begin{array}{rrrr|r}3&0&-1&0&0\\8&0&0&-2&0\\0&2&-2&-1&0\end{array}\right]\]
Passo 2 · escalone (laboratório)

Posto 3 < 4 incógnitas: SPI com 1 variável livre. Tomando \(x=t\): \(z=3t\), \(w=4t\), \(y=\frac{2z+w}{2}=5t\).

Passo 3 · menor solução inteira

\(t=1\): \(x=1,\ y=5,\ z=3,\ w=4\).

Resposta: \(\text{C}_3\text{H}_8+5\,\text{O}_2\to3\,\text{CO}_2+4\,\text{H}_2\text{O}\). As soluções \(t(1,5,3,4)\) formam uma reta: um subespaço de dimensão 1.

Exemplos resolvidos

Exemplo 1 · SI

Classifique \(\begin{cases}x+y+z=1\\2x+2y+2z=3\end{cases}\).

Passo 1

\(L_2\leftarrow L_2-2L_1\) dá \([0\ 0\ 0\,|\,1]\): \(0=1\). Sistema impossível.

Exemplo 2 · homogêneo

Resolva \(\begin{cases}x+2y-z=0\\2x+4y-2z=0\end{cases}\).

Passo 1

A 2ª é o dobro da 1ª: sobra \(x=-2y+z\), com \(y=s\), \(z=t\) livres.

Solução
\[(x,y,z)=s(-2,1,0)+t(1,0,1)\]

Um plano pela origem.

Hora do desafio

Verificação rápida de tudo o que foi visto no módulo

O pivô de uma linha é:

  1. o maior número da linha
  2. o primeiro número não nulo da linha
  3. o último número
  4. sempre 1
Na forma escalonada (não reduzida) o pivô pode ser qualquer número não nulo.

Homogêneo com 3 equações e 5 incógnitas é:

  1. SI
  2. SPD
  3. depende
  4. SPI
Posto ≤ 3 < 5 incógnitas e homogêneo nunca é SI.

Na solução \((2-t,\ 1-t,\ t)\), o conjunto das soluções é:

  1. uma reta
  2. um ponto
  3. um plano
  4. vazio
Um parâmetro: ponto \((2,1,0)\) mais múltiplos de \((-1,-1,1)\).

Por que escalonar ajuda em espaços vetoriais?

  1. Não ajuda
  2. Só serve para calcular determinantes
  3. Porque perguntas sobre vetores viram sistemas lineares
  4. Porque elimina os vetores
