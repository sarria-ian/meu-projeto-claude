Objetivos de aprendizagem

Ao final deste módulo você será capaz de:

  • verificar se um conjunto é base (LI e gera);
  • conhecer as bases canônicas e as dimensões de \(\mathbb R^n\), \(M_{m\times n}\) e \(P_n\);
  • extrair uma base de um conjunto gerador e completar um LI até uma base;
  • achar base e dimensão de subespaços dados por equações;
  • usar \(\dim(U+W)=\dim U+\dim W-\dim(U\cap W)\).

7.1 O que é base

Definição

Um conjunto \(B=\{v_1,\dots,v_n\}\subset V\) é uma base de \(V\) se:

(i) \(B\) é LI; e (ii) \(B\) gera \(V\): \([B]=V\).

Gera = “dá para fazer tudo”; LI = “sem desperdício”. Uma base é um conjunto gerador mínimo (ou um LI máximo).

7.2 Dimensão

Teorema e definição

Todas as bases de um mesmo espaço têm o mesmo número de vetores. Esse número é a dimensão: \(\dim V\).

Consequências (num espaço de dimensão n)

1. Mais de \(n\) vetores são LD. 2. Menos de \(n\) vetores não geram \(V\). 3. Exatamente \(n\) vetores: LI \(\iff\) geram \(\iff\) base. (Basta testar uma das duas condições!) 4. Se \(W\) é subespaço de \(V\), \(\dim W\le\dim V\), com igualdade só se \(W=V\).

Por isso os subespaços de ℝ³ são só aqueles

Dimensões possíveis: 0 (\(\{0\}\)), 1 (retas pela origem), 2 (planos pela origem), 3 (\(\mathbb R^3\)). Era a lista do Módulo 4.

7.3 Extraindo e completando bases

Extrair uma base de [S]

Coloque os vetores de \(S\) como colunas e escalone. Os vetores originais nas colunas com pivô formam uma base de \([S]\); \(\dim[S]=\) número de pivôs = posto.

Exemplo guiado

Ache uma base e a dimensão de \([(1,2,3),(2,4,6),(0,1,1),(1,3,4)]\).

Passo 1 · escalone (laboratório abaixo)

Pivôs nas colunas 1 e 3. (A coluna 2 é \(2v_1\); a coluna 4 é \(v_1+v_3\).)

Passo 2

Base: \(\{(1,2,3),(0,1,1)\}\), dimensão 2: um plano.

Completar um LI até uma base de ℝⁿ

Escreva os vetores LI e, depois deles, \(e_1,\dots,e_n\). Escalone e fique com as colunas de pivô: os seus vetores continuam lá, e os canônicos escolhidos completam a base.

Laboratório: base e dimensão de [S] (e completar até ℝⁿ)

Digite um conjunto de vetores. O laboratório extrai uma base do subespaço gerado, informa a dimensão e sugere quais canônicos acrescentar para chegar a uma base de \(\mathbb R^n\).

7.4 Base de um subespaço dado por equações

Roteiro

Resolva o sistema homogêneo das equações; escreva a solução geral com parâmetros; os vetores que multiplicam cada parâmetro formam uma base. Dimensão = número de variáveis livres = nº de incógnitas − posto.

Exemplo guiado

\(W=\{(x,y,z,w)\in\mathbb R^4:\ x+y-z=0,\ y+w=0\}\).

Passo 1 · isole as variáveis de pivô

\(y=-w\); \(x=z-y=z+w\). Livres: \(z=s\), \(w=t\).

Passo 2 · separe os parâmetros
\[(s+t,\ -t,\ s,\ t)=s(1,0,1,0)+t(1,-1,0,1)\]
Base: \(\{(1,0,1,0),(1,-1,0,1)\}\); \(\dim W=2\) (4 incógnitas − 2 equações independentes).
Fórmula da dimensão da soma
\[\dim(U+W)=\dim U+\dim W-\dim(U\cap W)\]

Parece a contagem de elementos de uma união: o que está nos dois foi contado duas vezes. Ex.: dois planos distintos pela origem em \(\mathbb R^3\): \(U+W=\mathbb R^3\), então \(3=2+2-\dim(U\cap W)\Rightarrow\dim(U\cap W)=1\): eles se cortam numa reta.

Exemplo prático · estudo de caso

Quantos números você realmente precisa guardar?

Um sensor mede, num ponto de uma fábrica, 4 grandezas \((T_1,T_2,T_3,T_4)\) (temperaturas em lugares diferentes). Pela física do equipamento, sempre valem \(T_1+T_2-T_3=0\) e \(T_2+T_4=0\) (em escalas relativas). Quantos números o sistema precisa transmitir por medição?

Passo 1

As medições possíveis formam exatamente o subespaço \(W\) da seção 7.4.

Passo 2

\(\dim W=2\), com base \(\{(1,0,1,0),(1,-1,0,1)\}\). Toda medição é \(s(1,0,1,0)+t(1,-1,0,1)\).

Passo 3

Basta transmitir \((s,t)=(T_3,T_4)\) e reconstruir \(T_1=T_3+T_4\), \(T_2=-T_4\).

Resposta: 2 números em vez de 4. A dimensão mede quantos “graus de liberdade” um conjunto de dados realmente tem; é a ideia por trás da compressão de dados e da redução de dimensão em ciência de dados.

Exemplos resolvidos

Exemplo 1

\(\{(1,1),(1,-1)\}\) é base de \(\mathbb R^2\)?

Atalho

São 2 vetores em dimensão 2: basta LI. \(\det=-1-1=-2\ne0\). É base.

Exemplo 2

Dimensão das matrizes \(2\times2\) simétricas.

Passo 1
\[\begin{bmatrix}a&b\\b&c\end{bmatrix}=a\begin{bmatrix}1&0\\0&0\end{bmatrix}+b\begin{bmatrix}0&1\\1&0\end{bmatrix}+c\begin{bmatrix}0&0\\0&1\end{bmatrix}\]

Três matrizes LI que geram: dimensão 3.

Exemplo 3

Dimensão de \(\{p\in P_3:\ p(1)=0\}\).

Hora do desafio

Verificação rápida de tudo o que foi visto no módulo

Base é um conjunto:

  1. só LI
  2. LI e gerador
  3. só gerador
  4. de vetores unitários
As duas condições juntas.

Dois vetores podem gerar \(\mathbb R^3\)?

  1. sim, se forem LI
  2. sim, se forem perpendiculares
  3. sim, sempre
  4. não, nunca
Menos de 3 vetores não geram um espaço de dimensão 3.

Para extrair uma base de [S], ficamos com:

  1. os vetores originais das colunas com pivô
  2. as linhas zeradas
  3. os vetores da forma escalonada, sempre
  4. os vetores canônicos
As colunas com pivô indicam quais vetores originais são LI e geram o mesmo espaço.

A dimensão do espaço de soluções de \(AX=0\) é:

  1. o posto
  2. o número de equações
  3. o número de variáveis livres
  4. sempre 1
Cada variável livre dá um vetor da base.
