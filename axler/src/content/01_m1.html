1.1 Conjuntos, pertinência e produto cartesiano

1 Intuição e conceito central

Um conjunto é uma coleção de objetos, sem ordem e sem repetição. Toda a Álgebra Linear é escrita nessa linguagem: um espaço vetorial é um conjunto \(V\) “equipado” com duas regras de combinar elementos.

Tabela de símbolos (leia em voz alta)
\(x\in A\)“\(x\) pertence a \(A\)”: \(x\) é um elemento de \(A\). \(A\subset B\)“\(A\) está contido em \(B\)”: todo elemento de \(A\) é elemento de \(B\). \(\varnothing\)conjunto vazio: não tem elemento nenhum. \(\{x\in A: P(x)\}\)“os \(x\) de \(A\) tais que \(P(x)\) é verdadeira”. \(A\times B\)produto cartesiano: o conjunto dos pares ordenados \((a,b)\) com \(a\in A\), \(b\in B\). \(\mathbf F\)no Axler, \(\mathbf F\) é sempre \(\mathbf R\) ou \(\mathbf C\) (Módulo 2). Seus elementos são os escalares.
Esquema mental do produto cartesiano

Pense em \(A\times B\) como uma tabela: as linhas são os elementos de \(A\), as colunas os de \(B\); cada célula é um par \((a,b)\). Se \(A=\{1,2\}\) e \(B=\{x,y,z\}\), a tabela tem \(2\times3=6\) células: \((1,x),(1,y),(1,z),(2,x),(2,y),(2,z)\). O par é ordenado: \((1,x)\ne(x,1)\).

1.2 Funções e operações

Definição · função

Uma função \(f:A\to B\) é uma regra que associa a cada elemento \(a\in A\) exatamente um elemento \(f(a)\in B\). \(A\) é o domínio e \(B\) o contradomínio.

Três exigências escondidas: (i) todo \(a\) tem imagem; (ii) a imagem é única; (iii) a imagem está em \(B\).

Operação = função

Uma operação (binária) num conjunto \(V\) é uma função \(V\times V\to V\): ela recebe um par \((u,v)\) e devolve um elemento de \(V\), que escrevemos \(u+v\). É exatamente assim que o Axler define “adição” em 1.19.

Consequência que você vai usar o tempo todo

Se \(x=y\), então \(x+z=y+z\) e \(\lambda x=\lambda y\). Motivo: a operação é uma função, e uma função aplicada ao mesmo objeto dá o mesmo resultado. É isso que autoriza “somar o mesmo vetor dos dois lados” de uma igualdade nas provas da seção 1B.

1.3 Quantificadores: ∀ e ∃ (e por que a ordem importa)

Símbolos
\(\forall\)“para todo”, “qualquer que seja”.\(\exists\)“existe (pelo menos um)”.\(\exists!\)“existe um único”.

Compare as duas exigências da definição de espaço vetorial:

Identidade aditiva

\(\exists\,0\in V\ \ \forall v\in V:\ v+0=v\). Um mesmo \(0\) funciona para todos os vetores.

Inverso aditivo

\(\forall v\in V\ \ \exists w\in V:\ v+w=0\). Cada \(v\) tem o seu \(w\); o \(w\) depende de \(v\).

Negação

A negação de “\(\forall x,\ P(x)\)” é “\(\exists x\) tal que \(P(x)\) é falsa”: para derrubar uma afirmação universal basta um contraexemplo. A negação de “\(\exists x,\ P(x)\)” é “\(\forall x\), \(P(x)\) é falsa”: para mostrar que algo não existe, é preciso examinar todos os candidatos.

1.4 Como se escreve uma prova (regras do jogo)

Cadeia de igualdades justificadas

Uma prova típica do Axler é uma linha como \(a=b=c=d\). Cada “=” precisa de um motivo: um axioma, uma definição, ou um resultado já provado. Nesta apostila, escrevemos o motivo em cima de cada igualdade:

\(x\)motivo 1\(=\)\(y\)motivo 2\(=\)\(z\)
Prova de unicidade

Para provar “existe um único objeto com a propriedade \(P\)”: suponha que dois objetos \(a\) e \(a'\) têm a propriedade e mostre que \(a=a'\). (É o esquema de 1.26 e 1.27.)

Prova de “A ou B”

Suponha que A é falsa e prove B. (Se A for verdadeira, não há nada a fazer.) É o esquema do exercício 2: “se \(a\ne0\), então \(v=0\)”.

2 Demonstração guiada

Proposição. Em \(\mathbf R\) (com a soma usual), se \(a+x=a\) para algum número \(a\), então \(x=0\).

Passo 1 · hipótese

Temos \(a+x=a\).

Passo 2 · somar \(-a\) dos dois lados

(Permitido porque a soma é uma função: objetos iguais somados a \(-a\) dão resultados iguais.)

\[(-a)+(a+x)=(-a)+a\]
Passo 3 · associatividade no lado esquerdo

(Reagrupamos sem mudar a ordem dos termos.)

\[((-a)+a)+x=(-a)+a\]
Passo 4 · \((-a)+a=0\) (inverso aditivo)
\[0+x=0\]
Passo 5 · \(0+x=x\) (identidade aditiva)
\[x=0\qquad\blacksquare\]
Repare

Usamos só: função (passo 2), associatividade, inverso e identidade. Nada específico de números reais! Por isso a mesma prova vai funcionar em qualquer espaço vetorial (é a “lei do cancelamento”, Módulo 6).

3 Exemplo resolvido em camadas
Problema

Uma operação “torta” em ℝ

Em \(\mathbf R\), defina \(x\ast y=x+y+1\). (a) \(\ast\) é comutativa e associativa? (b) Existe elemento neutro \(e\) (com \(x\ast e=x\) para todo \(x\))? Ele é único? (c) Todo \(x\) tem inverso (um \(y\) com \(x\ast y=e\))?

a) Estratégia de modelagem

Cada pergunta é uma frase com quantificadores. “Neutro” é \(\exists e\ \forall x\); “inverso” é \(\forall x\ \exists y\). Traduzimos cada uma numa equação e resolvemos.

b) Execução · comutativa e associativa

\(x\ast y=x+y+1=y+x+1=y\ast x\) (comutatividade da soma real).

\[(x\ast y)\ast z=(x+y+1)+z+1=x+y+z+2,\qquad x\ast(y\ast z)=x+(y+z+1)+1=x+y+z+2\]

Iguais: associativa.

b) Execução · neutro

Queremos \(x\ast e=x\) para todo \(x\): \(x+e+1=x\iff e=-1\). Como \(e=-1\) não depende de \(x\), o mesmo número serve para todos: existe neutro, \(e=-1\). Único: a equação \(x+e+1=x\) tem uma só solução.

b) Execução · inverso

Para cada \(x\), queremos \(y\) com \(x\ast y=-1\): \(x+y+1=-1\iff y=-x-2\). Esse \(y\) depende de \(x\) (e é o que a frase \(\forall x\ \exists y\) permite).

c) Análise crítica

A operação é a soma usual “deslocada”: se \(\varphi(x)=x+1\), então \(\varphi(x\ast y)=\varphi(x)+\varphi(y)\). Ou seja, \((\mathbf R,\ast)\) é uma cópia disfarçada de \((\mathbf R,+)\): o neutro \(-1\) é a imagem disfarçada do \(0\), e o inverso \(-x-2\) é o disfarce de \(-x\). Moral: o “zero” de uma estrutura não precisa ser o número 0. O laboratório do Módulo 4 mostra um espaço vetorial cujo vetor nulo é o número 1.

4 Pausa interativa

Desafio conceitual. Em \(\mathbf R\), considere as frases (I) \(\forall x\ \exists y:\ y>x\) e (II) \(\exists y\ \forall x:\ y>x\). Qual é verdadeira? Explique, com as suas palavras, por que a troca da ordem dos quantificadores muda a resposta, e relacione com a diferença entre “identidade aditiva” e “inverso aditivo”.

(I) é verdadeira

Dado qualquer \(x\), escolha \(y=x+1\). O \(y\) pode depender de \(x\).

(II) é falsa

Ela pede um único \(y\) maior que todos os reais. Se existisse, valeria \(y>y\) (tomando \(x=y\)), absurdo. Contraexemplo para qualquer candidato \(y\): \(x=y\).

Relação com a definição

“\(\exists\forall\)” exige um objeto universal (como o vetor \(0\), que serve a todos). “\(\forall\exists\)” permite um objeto sob medida para cada caso (como \(-v\), que depende de \(v\)). Confundir as duas leituras é um dos erros mais comuns ao ler definições.

Exercício técnico. Em \(\mathbf R\), defina \(x\circ y=xy+x+y\). (a) Ache o elemento neutro. (b) Quais números têm inverso em relação a \(\circ\)? Justifique cada passo.

a) Neutro

Queremos \(x\circ e=x\) para todo \(x\): \(xe+x+e=x\iff e(x+1)=0\). Para valer para todo \(x\) (inclusive \(x\ne-1\)), precisamos \(e=0\). E de fato \(x\circ0=0+x+0=x\). Neutro: \(e=0\).

b) Inversos

Queremos \(y\) com \(x\circ y=0\): \(xy+x+y=0\iff y(x+1)=-x\). Se \(x\ne-1\): \(y=\frac{-x}{x+1}\). Se \(x=-1\): a equação fica \(0=1\), impossível.

Conclusão e análise

Todo \(x\ne-1\) tem inverso; \(-1\) não. Repare: \(x\circ y=(x+1)(y+1)-1\), então \(\circ\) é a multiplicação “deslocada” por 1, e \(-1\) faz o papel do zero da multiplicação, que também não tem inverso. Por isso \((\mathbf R,\circ)\) não satisfaz um axioma do tipo “todo elemento tem inverso”.
