Objetivos de aprendizagem

Ao final deste módulo você será capaz de:

  • contar possibilidades com o princípio multiplicativo;
  • distinguir arranjo (a ordem importa) de combinação (a ordem não importa);
  • deduzir e usar \(\binom nk=\dfrac{n!}{k!\,(n-k)!}\), com o atalho de conta rápida;
  • usar as propriedades: \(\binom n0=\binom nn=1\), \(\binom n1=n\), binomiais complementares e igualdade de binomiais.

3.1 Princípio multiplicativo

Princípio fundamental da contagem

Se uma decisão tem \(m\) opções e, para cada uma delas, uma segunda decisão tem \(p\) opções, então as duas juntas têm \(m\cdot p\) possibilidades. Vale para quantas etapas houver: multiplique.

Exemplo: 3 camisetas, 2 bermudas e 2 tênis dão \(3\cdot2\cdot2=12\) looks.

Laboratório: a árvore de possibilidades

Cada nível da árvore é uma decisão. O número de folhas (looks) é o produto das opções.

3.2 Quando a ordem importa (arranjo) e quando não importa (combinação)

A ordem importa

Escolher presidente e vice entre 5 pessoas: Ana-presidente e Bia-vice é diferente de Bia-presidente e Ana-vice.

\[A_{5,2}=5\cdot4=20\]

Isso é um arranjo: \(A_{n,k}=n(n-1)\cdots(n-k+1)=\dfrac{n!}{(n-k)!}\).

A ordem não importa

Escolher uma dupla para um trabalho entre 5 pessoas: {Ana, Bia} é a mesma dupla que {Bia, Ana}.

\[\frac{20}{2}=10\ \text{duplas}\]

Isso é uma combinação. Cada dupla foi contada 2 vezes no arranjo (AB e BA), por isso dividimos por \(2!=2\).

Teste rápido

Troque a ordem dos escolhidos. Mudou o resultado? Então é arranjo. Não mudou (é o mesmo grupo)? Então é combinação. No Binômio de Newton só aparecem combinações.

3.3 A fórmula das combinações

Dedução passo a passo
Passo 1 · conte como se a ordem importasse

Escolher \(k\) entre \(n\) em ordem: \(n\) opções para o 1º, \(n-1\) para o 2º, …, \(n-k+1\) para o \(k\)-ésimo.

\[A_{n,k}=n(n-1)\cdots(n-k+1)=\frac{n!}{(n-k)!}\]
Passo 2 · cada grupo foi contado k! vezes

Um mesmo grupo de \(k\) pessoas pode ser enfileirado de \(k!\) jeitos, e o arranjo contou todos eles.

Passo 3 · divida
\[C_{n,k}=\frac{A_{n,k}}{k!}=\frac{n!}{k!\,(n-k)!}\]
Número binomial

O número de combinações de \(n\) elementos tomados \(k\) a \(k\) é escrito como número binomial (lê-se “\(n\) escolhe \(k\)” ou “binomial de \(n\) sobre \(k\)”):

\[\binom{n}{k}=C_{n,k}=\frac{n!}{k!\,(n-k)!},\qquad0\le k\le n\]

\(n\) é o numerador (de cima) e \(k\) é a classe (de baixo). Não é uma fração: não há traço no meio.

Conta rápida (sem calcular fatoriais enormes)

Em cima: \(k\) fatores descendo a partir de \(n\). Embaixo: \(k!\).

\[\binom{10}{3}=\frac{10\cdot9\cdot8}{3\cdot2\cdot1}=\frac{720}{6}=120\]
Laboratório: todas as combinações, uma por uma

Escolha quantas pessoas existem (\(n\)) e quantas serão escolhidas (\(k\)). Todos os grupos possíveis aparecem listados. Compare com o número de arranjos.

Laboratório: calculadora de números binomiais

A calculadora mostra a fórmula, o atalho do complementar e a conta rápida.

3.4 Propriedades dos números binomiais

PropriedadeFórmulaPor quê (em contagem)
Escolher nenhum / todos\(\binom n0=\binom nn=1\)Só há um jeito de não escolher ninguém, e um de escolher todos.
Escolher um\(\binom n1=\binom n{n-1}=n\)Basta apontar quem (ou quem fica de fora).
Complementares\(\binom nk=\binom n{n-k}\)Escolher \(k\) para entrar é escolher \(n-k\) para ficar de fora.
Igualdade de binomiais

Se \(\binom na=\binom nb\), então

\[a=b\qquad\text{ou}\qquad a+b=n\]

(ou são iguais, ou são complementares).

Exemplo guiado

Resolva \(\binom{12}{x}=\binom{12}{2x-3}\).

Caso 1 · iguais
\[x=2x-3\Rightarrow x=3\]

Confere: \(\binom{12}{3}=\binom{12}{3}\) ✓.

Caso 2 · complementares
\[x+(2x-3)=12\Rightarrow3x=15\Rightarrow x=5\]

Confere: \(\binom{12}{5}=\binom{12}{7}\) ✓ (e \(7\le12\)).

Resposta

\(x\in\{3,5\}\). Sempre confira se as classes ficam entre 0 e \(n\).

Exemplo prático · estudo de caso

Qual é a chance de ganhar na Mega-Sena com uma aposta simples?

Na Mega-Sena, você escolhe 6 números entre 60. A ordem dos números não importa. Quantos jogos diferentes existem? Qual é a chance de uma aposta acertar os 6?

Passo 1 · é combinação

{5, 12, 23, 34, 45, 56} é o mesmo jogo em qualquer ordem.

Passo 2 · conta rápida
\[\binom{60}{6}=\frac{60\cdot59\cdot58\cdot57\cdot56\cdot55}{6\cdot5\cdot4\cdot3\cdot2\cdot1}=\frac{36\,045\,979\,200}{720}=50\,063\,860\]
Passo 3 · probabilidade
\[P=\frac{1}{50\,063\,860}\approx0{,}000002\%\]
Resposta: 50 063 860 jogos possíveis; a chance de uma aposta simples é de 1 em mais de 50 milhões.

Exemplos resolvidos

Exemplo 1

Calcule \(\binom{8}{5}\).

Passo 1 · use o complementar (menos conta)
\[\binom85=\binom83=\frac{8\cdot7\cdot6}{3\cdot2\cdot1}=56\]
Exemplo 2

Numa sala com 20 pessoas, todos se cumprimentam uma vez com um aperto de mão. Quantos apertos de mão acontecem?

Passo 1

Cada aperto é uma dupla (ordem não importa).

\[\binom{20}{2}=\frac{20\cdot19}{2}=190\]
Exemplo 3

Resolva \(\binom{n}{2}=28\).

Passo 1
\[\frac{n(n-1)}{2}=28\Rightarrow n(n-1)=56=8\cdot7\Rightarrow n=8\]

Hora do desafio

Verificação rápida de tudo o que foi visto no módulo

\(\binom{n}{0}\) vale:

  1. 0
  2. 1
  3. \(n\)
  4. não existe
Só há um jeito de não escolher ninguém: \(\frac{n!}{0!\,n!}=1\).

Qual igualdade é verdadeira?

  1. \(\binom{9}{2}=\binom{9}{3}\)
  2. \(\binom{9}{2}=\frac{9}{2}\)
  3. \(\binom{9}{2}=\binom{9}{7}\)
  4. \(\binom92=18\)
Complementares: \(2+7=9\). E \(\binom92=36\).

Em \(A_{5,3}=60\) e \(\binom53=10\), por que dividimos 60 por 6?

  1. Cada grupo de 3 aparece em \(3!=6\) ordens
  2. Porque 6 = 5 + 1
  3. Para dar um número menor
  4. Porque há 6 pessoas
Um grupo {A, B, C} aparece como ABC, ACB, BAC, BCA, CAB, CBA no arranjo.

\(\binom{50}{48}\) é mais fácil de calcular como:

  1. \(\frac{50!}{48!}\)
  2. \(50\cdot48\)
  3. \(\binom{48}{2}\)
  4. \(\binom{50}{2}=\frac{50\cdot49}{2}=1225\)
Use o complementar: \(48+2=50\).
