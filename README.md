# meu-projeto-claude

## Apostila de Trigonometria

- `trigonometria/dist/apostila-trigonometria.html` — apostila interativa (arquivo único, funciona offline).
- `trigonometria/dist/apostila-trigonometria.zip` — pacote com a apostila, instruções (`LEIA-ME.txt`) e licença do KaTeX.
- `trigonometria/src/` — fontes. Para regenerar: `cd trigonometria/src && python3 build.py`.
